01

Install Scriptable

→

Free app from the App Store

Scriptable is the standard tool for custom iOS widgets. Open in App Store ↗

02

Find your Steam64 ID

→

The 17-digit number of your profile

Paste your Steam profile link at steamid.io ↗ — you'll get a string like 76561199002476923

03

Copy the widget code

→

Paste it into a new Scriptable script

In Scriptable: + → paste code → save. Nothing to edit.

// Leetify Stats Widget — public version // Nothing to edit in the code. // Steam ID goes into the widget parameter in step 4. const PROXY_URL = "https://leetify-widget.onrender.com"; // ... full code copied on click
04

Add the widget to your screen

→

Long-press screen → «+» → Scriptable

Pick a size (Small / Medium / Large), add it to your screen.

→

Enter your Steam ID in the parameter

Long-press the widget → Edit Widget → in the Parameter field type:

76561199002476923,full

Without ,full — compact mode (4 lines, no match).

How it works: the widget doesn't talk to Leetify directly — it goes through a proxy server that hides the API key and caches responses. Data refreshes roughly every 15 minutes, that's an iOS limitation, not the widget's.
